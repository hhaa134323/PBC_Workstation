PBC 智能管理工作站 · 混合形态测试数据包
========================================

本数据包在一个客户文件夹内混合了5种交付形态 + 3种特殊情况，
用于验证 Layer 0（结构感知）+ 四层漏斗分类架构。

使用步骤：
1. 启动 PBC 工作站
2. 创建新项目
3. 导入 01_PBC_List_混合形态.xlsx（20项，含9项未提供模拟缺料）
4. 客户文件夹指向 本目录/客户共享文件夹_混合形态/
5. 扫描新文件

目录结构：
  客户共享文件夹_混合形态/
    ├── 历-1_股权架构图.pdf          [形态1] filename-match
    ├── 销-1_销售合同台账.xlsx        [形态1] filename-match
    ├── 财务报表/                     [形态2] 文件夹名=类别
    │   ├── 合并资产负债表.xlsx
    │   └── 子公司利润表.xlsx
    ├── 存货盘点/
    │   └── 盘点表.xlsx
    ├── 盘点计划.pdf                  [形态3] 扁平有意义
    ├── DEF银行对账单.pdf
    ├── ABC集团章程_修订版.pdf
    ├── 2023年度/                    [形态4] 文件夹名=年份
    │   └── 银行流水.xlsx            [S3] 货-1拆3份
    ├── 2024年度/
    │   └── 银行流水.xlsx
    ├── 2025年度/
    │   └── 银行流水.xlsx
    ├── 新建文档(1).pdf               [形态5] LLM兜底→综-1
    ├── 扫描件001.pdf                 [S5] 清单外→未分类
    └── 穿行测试_销售收款控制/        [S1] 整目录归档
        ├── 系统截图_订单审批.pdf
        ├── 合同签字件.pdf
        └── 银行回单.pdf

验证目标：
  Layer 0: 感知到5种形态混合存在
  Layer 1: 形态1的2个文件秒级命中
  Layer 2: 形态2/3/4的文件百毫秒命中（用文件夹名/关键词线索）
  Layer 3: 形态5的2个文件走LLM（1个命中综-1, 1个未分类S5）
  S1: 穿行测试文件夹整目录归档
  S3: 货-1的3个年度文件全部匹配同一item_id
  S5: 扫描件001.pdf 低confidence→归档未分类+toast
