# PBC 工作站 完整业务流程交互测试 Prompt

> 给一个毫不知情的 AI 用。用 Playwright 打开浏览器，模拟审计员的完整操作，每步截图，记录异常。

## 环境

- 服务地址：http://127.0.0.1:8111
- 用 Playwright headless=False（有头模式），每步截图保存
- 截图目录：./screenshots/（自动创建）
- 测试数据：
  - PBC 清单：D:\AgentProjects\IpoPBC\0\data\test_data_package\01_PBC_List_混合形态.xlsx
  - 客户文件夹：D:\AgentProjects\IpoPBC\0\data\test_data_package\客户共享文件夹_混合形态
  - 归档目录：D:\AgentProjects\IpoPBC\0\projects\test_interactive

## 测试步骤

### 第一步：打开首页
- 打开 http://127.0.0.1:8111
- 等页面加载完
- 截图 01_home.png
- 期望：页面正常显示，不白屏，有项目列表或 onboarding 向导

### 第二步：新建项目
- 点「新建项目」（或如果需要的话用 API 创建）
- 项目名：交互测试项目
- 配置客户共享文件夹路径（上面的路径）
- 配置归档目录路径
- 导入 PBC 清单
- 截图 02_new_project.png
- 期望：项目创建成功，PBC 清单有 19 项

### 第三步：看待初检 tab
- 点「待初检」tab
- 截图 03_triage.png
- 期望：显示客户文件夹路径 + 文件数 + 扫描按钮 + 拖拽区
- 异常检查：不应该显示"尚未配置客户共享文件夹"

### 第四步：看 AI 配置
- 点右上角「设置」→「AI 配置」
- 截图 04_ai_config.png
- 期望：
  - API Key 已设置（显示 sk-xxx***xxx）
  - 模型名：qwen-plus
  - 有 3 个开关：文件名直配、人机协同、自动归档高置信度
  - 人机协同开关是开的
- 点取消关闭

### 第五步：扫描文件
- 回到待初检 tab
- 点「扫描新文件」按钮
- 等扫描完成（进度条走完）
- 截图 05_scan_done.png
- 期望：扫描完成，显示汇总（扫描了 N 份文件）
- 异常检查：不应该弹一堆"文件缺失"toast

### 第六步：看待归档 tab
- 点「待归档」tab
- 截图 06_pending_archive.png
- 期望：
  - 顶栏待归档数字 > 0
  - 列表显示文件名 + 建议 item_id + 置信度（或"整目录归档"标签）
  - 每条有 3 个按钮：确认归档、改分类、跳过
  - 有"全部归档"按钮

### 第七步：确认单个文件归档
- 在待归档列表找一个文件类型（不是"整目录归档"的）
- 点「确认归档」
- 截图 07_confirm.png
- 期望：
  - 显示 toast"已归档"
  - 该条从列表消失
  - 顶栏待归档数字减 1

### 第八步：跳过一个
- 在待归档列表找一个
- 点「跳过」
- 截图 08_skip.png
- 期望：该条从列表消失，显示"已跳过"toast

### 第九步：改分类
- 在待归档列表找一个
- 点「改分类」
- 弹窗里选一个不同的 item_id
- 点确认改分类
- 截图 09_reclassify.png
- 期望：显示"已改分类"toast，该条的建议 item_id 变了

### 第十步：批量归档
- 点「全部归档」按钮
- 截图 10_batch.png
- 期望：所有剩余待归档归档完成，待归档列表清空

### 第十一步：看已完成 tab
- 点「已完成」tab
- 截图 11_done.png
- 期望：显示已归档的 PBC 项，状态=已提供

### 第十二步：看文件区
- 点「文件区」tab
- 截图 12_file_zone.png
- 期望：
  - 左侧客户文件夹显示文件列表
  - 右侧已归档树显示归档目录（按一级分类分组）
  - 归档树不应该有重复目录或空目录

### 第十三步：看超期 tab
- 点「超期未提供」tab
- 截图 13_overdue.png
- 期望：显示热力图 + 高风险项列表

### 第十四步：看文件变更面板
- 点右上角「文件变更」按钮
- 截图 14_change_panel.png
- 期望：右侧滑出面板，显示变更日志列表（有 archived 记录）
- 按 Esc 关闭

### 第十五步：点 PBC 表格行
- 回到待初检或已完成 tab
- 点一个 PBC 行的操作按钮（如果有）
- 截图 15_pbc_row.png
- 期望：能查看详情或修改状态

### 第十六步：检查归档目录
- 在文件区点"打开归档目录"
- 截图 16_archive_dir.png
- 期望：文件夹打开，显示按一级分类的目录结构

## 异常记录

每步检查：
1. 有没有 JS 报错（F12 console）
2. 有没有 4xx/5xx 网络请求
3. 有没有白屏
4. 有没有显示不该显示的内容（如"尚未配置"）
5. 按钮点击有没有响应
6. 有没有重复/空目录

把每步的异常记录到报告里，截图保存。

## 输出

最后输出一份报告：
- 总共多少步
- 每步 PASS/FAIL
- FAIL 的具体问题 + 截图路径
- 发现的所有异常（JS 报错、网络错误、UI 问题）
