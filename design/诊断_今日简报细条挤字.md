# 诊断：今日简报收起态细条“字全挤在一起”

日期：2026-07-27
修订者：前端设计复核
适用文件：`app/static/index.html`（单文件 SPA）
执行者：本地 GLM

---

## 一、结论先行

一处修改，只改一个 `div` 的内联 `style` 与其 5 个子 `span` 的内联 `style`。

- **不改** 外壳：白底、`border-left:3px solid hsl(var(--ey-yellow))`、`border-radius:10px`、`box-shadow`、`border`
- **不改** 任何颜色变量、字体、审计状态色
- **不改** Alpine 逻辑：`x-show`、`@click="toggleBriefFold()"`、`x-text` 表达式全部原样保留
- **不新增** CSS 类、不动 `pbc-enhance.css` / `pbc-enhance.js`
- **不动** 展开态大卡片（紧接在后面那个 `div`）

符合 `REVIEW_CONTEXT.md` 第 5 条约束：最小侵入，只改样式值。

## 二、现状与证据链

### 2.1 定位

`app/static/index.html`，注释 `<!-- 收起时：细条 -->` 之下那一个 `div`（约第 1250 行）。它的上一行是：

```html
<!-- 今日简报（Alpine 原生控制，不用 pbc-enhance.js） -->
```

### 2.2 四个具体成因

| # | 现状值 | 为何导致“挤” |
|---|---|---|
| 1 | 容器 `gap:10px` | 中文无词间空格，10px 不够断句，三段糊成一行 |
| 2 | 三段无任何分隔物 | 没有竖线 / 底色 / 大留白，眼睛找不到边界 |
| 3 | 中间段只有 `overflow:hidden;text-overflow:ellipsis`，**没有 `flex:1;min-width:0`** | flex 默认 `flex-shrink:1`，中间段会被右侧元素挤缩到省略号。右侧“展开”又用 `margin-left:auto` 抢剩余空间，两下叠加就是“全挤在一起”的直接原因 |
| 4 | 字号 `13 / 12.5 / 11px`，且末段 `opacity:.7` | 12.5 与 13 几乎看不出差异，层次靠“字变小”而不是“颜色变浅”；11px + opacity .7 变浑浊而非次要 |
| 5 | `padding:10px 16px` → 实际高度约 40px | 垂直方向也紧，没有呼吸空间 |
| 6 | 右侧“展开”是裸文字 | 不像可点，也没有 hit area |
| 7 | 圆点固定绿色 `var(--green,#16a34a)` | 19 处变动未分析时依旧是绿点，语义错位 |

## 三、修法（可直接 Edit）

### 3.1 容器 div

**oldStr**（只改 `style` 属性值，`x-show` 与 `@click` 原样不动）：

```
style="display:flex;align-items:center;gap:10px;padding:10px 16px;margin-bottom:16px;background:hsl(var(--card));border:1px solid hsl(var(--border));border-left:3px solid hsl(var(--ey-yellow));border-radius:10px;cursor:pointer;transition:.15s;box-shadow:0 1px 2px rgba(26,26,36,.06)"
```

**newStr**：

```
style="display:flex;align-items:center;gap:0;height:50px;padding:0 14px 0 16px;margin-bottom:16px;background:hsl(var(--card));border:1px solid hsl(var(--border));border-left:3px solid hsl(var(--ey-yellow));border-radius:10px;cursor:pointer;transition:.15s;box-shadow:0 1px 2px rgba(26,26,36,.06)"
```

改动点：`gap:10px` → `gap:0`（间距改由分隔线的 margin 控制）；`padding:10px 16px` → `height:50px;padding:0 14px 0 16px`。

### 3.2 五个子元素

**圆点**——加 `margin-right:10px`，颜色改为按是否有待分析变动切换（审计状态色不变，这里用的是提醒色）：

```html
<span :style="'width:8px;height:8px;border-radius:99px;flex-shrink:0;margin-right:10px;background:'+(briefHasDelta?'hsl(38 92% 50%)':'hsl(142 71% 45%)')"></span>
```

**标题**——加字距，其余不动：

```html
<span style="font-size:13px;font-weight:700;flex-shrink:0;letter-spacing:-.1px">今日简报</span>
```

**新增发丝竖线**（插在标题之后）：

```html
<span style="width:1px;height:15px;background:hsl(var(--border));flex-shrink:0;margin:0 16px"></span>
```

**结论句**——关键：加 `flex:1;min-width:0`，字号 12.5 → 13，颜色由 muted 改为 foreground（`x-text` 表达式一字不改）：

```html
<span style="flex:1;min-width:0;font-size:13px;color:hsl(var(--foreground));overflow:hidden;text-overflow:ellipsis;white-space:nowrap" x-text="...原表达式不变..."></span>
```

**再插一道同样的发丝竖线**。

**上次查看**——去掉 `opacity:.7`，11px → 12px：

```html
<span x-show="briefSeenStr" style="flex-shrink:0;font-size:12px;color:hsl(var(--muted-foreground));white-space:nowrap" x-text="'上次查看 '+briefSeenStr"></span>
```

**展开**——去掉 `margin-left:auto`（不再需要，中间段已经 `flex:1`），改成 28px 高胶囊 + chevron：

```html
<span style="display:inline-flex;align-items:center;gap:5px;flex-shrink:0;height:28px;padding:0 10px;margin-left:14px;border-radius:6px;background:hsl(var(--muted));font-size:12.5px;font-weight:600;color:hsl(var(--foreground));white-space:nowrap">展开<svg width="13" height="13" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.4" stroke-linecap="round" stroke-linejoin="round"><path d="m6 9 6 6 6-6"/></svg></span>
```

> chevron 用 Lucide `chevron-down`，符合零 emoji 约束。

## 四、验收标准

1. 硬刷新 `Ctrl+Shift+R`，默认收起态细条可见
2. 细条高度 = **50px**（devtools 量）
3. 三段之间能看到两道 1px 竖线，竖线左右各 16px
4. 窗口宽度从 1920 拉到 1280，中间结论句**不提前变省略号**，右侧“上次查看”与“展开”不被压缩
5. 鼠标移上整条仍是 `cursor:pointer`，点任意位置能展开
6. 展开 → 收起 → 刷新，折叠状态保持（回归验证，不应因本改动变化）
7. Console 零报错；`document.querySelectorAll('.pbcg-brief-off').length === 0`

- 不要陇修展开态大卡片。它是单独的 `div`，本次不在范围

## 六、附注：本地与仓库可能不一致

```
briefHasDelta ? '文件夹 '+(briefingDelta.delta_count||0)+' 处变动待分析' : ...
```

这不影响本次修改：本文只改容器与子元素的 `style`，**不要动任何 `x-text` 表达式**。若本地 `oldStr` 匹配不上，以本地实际内容为准，只按 3.1 / 3.2 的改动点逐项对应替换。
