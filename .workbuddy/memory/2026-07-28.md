## 整目录归档置信度=0 修复（21:28）

### 根因
`routes_files.py` 行 1270 `confidence=0.0` 写死，不管匹配方式
- 文件名精确匹配（目录名含 item_id）→ 应该 1.0（规则匹配，确定性）
- AI 兜底匹配 → 应该用 AI 返回的 confidence
- 都没匹配 → 才 0.0（待人工）

### 修复（routes_files.py _process_one_directory）
`confidence=0.0` 改成按匹配方式：
```python
_dir_confidence = 0.0
if item_id:
    if fname_matched:
        _dir_confidence = 1.0  # 规则匹配
        _dir_decision = "auto"
    else:
        _dir_confidence = float(classify.get("confidence") or 0)  # AI 兜底
        _dir_decision = "suggest"
```
decision 也从写死 "walkthrough" 改成 "auto"/"suggest"（区分规则匹配和 AI 匹配）
