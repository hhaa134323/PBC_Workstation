## 思考强度配置补丁（22:20）
用户追问能否调节思考强度。研究后确认：

**GLM-5.2 思考强度只有 2 档**（不是 4 档）：
- `max`（默认，最强推理，烧 token 多，适合复杂编码/推理）
- `high`（中等，省钱省时，适合日常）
- `low`/`medium` 会 fallback 到 max（不是独立档位）

**控制方式**（API 调用层面）：
- `enable_thinking: false` → 完全关闭思考
- `enable_thinking: true` + `reasoning_effort: "high"/"max"` → 调强度
- 百炼 OpenAI 兼容模式：通过 `extra_body` 传 `enable_thinking` 和 `reasoning_effort`

**WorkBuddy 端**：`models.json` 支持 `reasoning` 字段（DeepSeek 教程验证过）：
```json
"reasoning": {
  "defaultEffort": "high",
  "supportedEfforts": ["high", "max"]
}
```
