### 关键教训
1. **Bash heredoc 不能用于含单引号的长字符串**——遇到 ' 引号就截断。改用 Python 多行字符串 + Write 工具，或 Edit 工具按段改。
2. **改 index.html 这种大文件，最小侵入式 Edit 比 Write 重写稳**——Write 工具有截断限制，重写容易出 bug。
3. **沙箱限制 PyInstaller 不能删 build/dist 已存在目录**——每次打包换个名字（v2/v3），或者用 --noconfirm + 不同 --name。
